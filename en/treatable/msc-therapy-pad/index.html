Disease Arteri Perifer (PAD) is kondisi di mana arteri which bring darah from jantung ke feet menyempit or tersumbat because aterosklerosis (penumpukan plak), menyebabkan aliran darah which terbatas.

Because pembuluh darah di feet not can mensuplai darah with cukup, patient mengalami gejala seperti nyeri betis, kesemutan saat berjalan (which mereda saat istirahat), and pada kasus which parah, nyeri feet which hebat bahkan saat istirahat, luka which sulit sembuh, or ulkus di ujung feet.

PAD which berkembang disebut Iskemia Member Gerak Kritis (Critical Limb Ischemia, CLI), kondisi serius di mana jika dibiarkan can mengakibatkan gangren and pada kasus terburuk amputasi feet.

When arteri menyempit because plak, aliran darah memburuk, and otot and kulit di feet not receive oksigen and nutrisi which cukup, which menjadi penyebab gejala PAD.

For PAD, treatment pertama-tama bertujuan mencegah perkembangan and meringankan gejala through modifikasi gaya hidup and therapy farmakologis (drug for mengencerkan darah or melebarkan pembuluh darah, dll).

Selain that, when penyumbatan pembuluh darah parah, procedure angioplasti berbasis kateter (misalnya angioplasti transluminal perkutan (PTA) or penempatan stent) or operasi rekonstruksi vaskular bedah seperti bypass performed.

Meskipun many patient meningkat with treatment this, there is many kasus di mana aterosklerosis meluas ke seluruh feet membuat operasi sulit, or patient not can mentoleransi operasi because komplikasi parah.

Faktanya, sekitar 10-30% patient CLI parah dikatakan "not there is indikasi (no-option)" for rekonstruksi vaskular, and saat this pilihan treatment which effective terbatas. In kasus-kasus sulit for diobati this, nyeri and ulkus not membaik, and pada akhirnya sebagian feet mungkin harus diamputasi.

Di antara keterbatasan treatment saat this, there is kebutuhan kuat for pengembangan method treatment baru bagi patient which berharap "entah how mempertahankan feet I sendiri".

Disease Arteri Perifer and Stem cell therapy: Possibility Baru Drug Regenerative

Oleh because that, which mendapat perhatian baru-baru this is pendekatan baru through drug regenerative use stem cell therapy. Stem cell therapy is method treatment which use "stem cell", cell which membentuk dasar tubuh kita, for mempromosikan regeneration jaringan which rusak.

For feet with aliran darah which terbatas because penyumbatan arteri, tujuannya is for menyuntikkan stem cell and menciptakan pembuluh darah baru from in tubuh for enhance aliran darah. Daripada "secara artifisial membuat jalur bypass" with operasi bypass, citra this is mempromosikan pembentukan bypass alami (sirkulasi kolateral) with kekuatan which dimiliki stem cell.

Faktanya, for patient CLI which not have pilihan treatment konvensional, pendekatan drug regenerative seperti this diharapkan sebagai strategi baru.

There is berbagai jenis stem cell, tetapi which terutama used in drug regenerative for disease arteri perifer is mesenchymal stem cell (Mesenchymal Stem Cells, MSC) or cell mononuklear which berasal from sumsum tulang and darah perifer.

Secara special, MSC can diekstrak from berbagai bagian tubuh seperti sumsum tulang, jaringan lemak, and tali center (tali center), and with membudayakan and meningkatkannya, jumlah cell which diperlukan can diamankan, membuat MSC sebagai sumber cell which kuat for drug regenerative.

MSC have ability which unggul in menghasilkan faktor pertumbuhan which meregenerasi pembuluh darah and menekan peradangan, and has show bahwa that can berkontribusi pada perbaikan disease arteri perifer. Di antara which mendapat perhatian baru-baru this is stem cell which berasal from tali center which diambil from "Wharton's Jelly", jaringan seperti gelatin in tali center (Wharton's Jelly-derived MSC, WJ-MSC).

This is stem cell which obtained from jaringan which obtained pada saat kelahiran bersama plasenta, with many keuntungan termasuk ability proliferasi and diferensiasi which tinggi, not perlu mengekstrak cell from tubuh patient sendiri reduce beban, and can provided for many patient with membudayakan and meningkatkannya.

Selain that, dilaporkan bahwa WJ-MSC have ability tinggi in mensekresikan zat which terlibat in angiogenesis and anti-inflammation, and mengharapkan many hal sebagai sumber cell for drug regenerative for disease arteri perifer.

Mekanisme Kerja Stem cell therapy for Disease Arteri Perifer

Stem cell therapy dianggap effective for disease arteri perifer because stem cell is "terapis multifungsi" which perform many peran secara bersamaan. Mekanisme aksi berikut known for stem cell therapy secara spacious.

Menumbuhkan pembuluh darah baru (promosi angiogenesis):

Stem cell mensekresikan sejumlah large zat which disebut faktor pertumbuhan and sitokin which berfungsi sebagai sinyal "membuat pembuluh darah" di jaringan which rusak. Berkat this, cell sekitar diaktifkan and kapiler baru memanjang, membentuk bypass pembuluh darah alami pada tingkat cell (disebut formasi sirkulasi kolateral).

Misalnya, cell mononuklear which berasal from sumsum tulang mengandung cell prekursor endotel (EPC), and with dimasukkan ke in dinding pembuluh darah baru sebagai bagian from pembuluh darah which baru terbentuk, also dilaporkan for memperkuat jaringan pembuluh darah.

Tindakan menekan peradangan (anti-inflamasi dan modulasi imun):

Di daerah with aliran darah bad, selain kerusakan jaringan from penyumbatan pembuluh darah, there is reaksi inflammation which terjadi, and peradangan this more merusak pembuluh darah and jaringan in siklus which merugikan.

Stem cell also melepaskan sitokin anti-inflammation which menenangkan peradangan, apply gaya penyelamat for system kekebalan which overexcited. With this, kerusakan jaringan from peradangan which not perlu and sense sakit mereda, and lingkungan penyembuhan disusun.

Tindakan melindungi jaringan dan mempromosikan perbaikan (perlindungan sel dan anti-fibrosis):

Zat which disekresikan oleh stem cell not hanya angiogenesis and anti-inflammation tetapi also tindakan melindungi cell-cell jaringan and menekan fibrosis (parut).

With send faktor perlindungan cell (faktor sitoprotektif) which bekerja "bertahananlah for hidup!" ke cell otot rangka which kesulitan because kekurangan oksigen, membantu menghentikan kematian jaringan. Selanjutnya, peradangan which parah selama periode kekurangan oksigen sering menyebabkan jaringan which terluka menjadi kaku and mengeras (fibrosis). Stem cell have fungsi mencegah hal this.

Stem cell therapy melibatkan suntikan cell seperti mesenchymal stem cell which berasal from sumsum tulang (BM-MSC), cell mononuklear (BM-MNC), or cell prekursor from darah perifer (EPC) ke area feet with aliran darah which bad. Cell-cell this, pertama-tama, mensekresikan zat bioaktif seperti faktor pertumbuhan, sitokin, and enzim for mempromosikan regeneration pembuluh darah. With this, will more mudah for membentuk kapiler baru di jaringan sekitar, and aliran darah membaik.

More lanjut, stem cell melepaskan zat which menenangkan peradangan, menekan kerusakan which terjadi akibat reaksi kekebalan which berlebihan. Selain that, they also have fungsi mencegah "fibrosis (parut)" di mana jaringan which rusak menjadi kaku.

With tindakan-tindakan this from stem cell, cell-cell seperti otot rangka which mengalami kerusakan because kekurangan oksigen and nutrisi dilindungi, and struktur and fungsi otot and kulit more mudah dipertahankan.

With cara this, stem cell therapy not hanya "membuat pembuluh darah" tetapi also pemulihan aliran darah, pengendalian peradangan, and perlindungan and perbaikan jaringan through many efek, berkontribusi pada peringan gejala disease arteri perifer and promosi pemulihan.

Bukti Efektivitas Stem cell therapy for Disease Arteri Perifer

Stem cell therapy have harapan teoritis, tetapi poin "apakah true-true effective?" is which penting.

Faktanya, selama sekitar 20 tahun terakhir, many research clinical stem cell therapy pada patient PAD and CLI has performed di seluruh world. Sebagai hasilnya, data positif which show efektivitas stem cell therapy secara bertahap terakumulasi.

Misalnya, di Jepang, pada tahun 2002, uji coba pemberian suntikan cell sumsum tulang patient CLI they ke feet performed, and peringan sense sakit feet, percepatan penyembuhan ulkus, and bahkan penurunan tingkat amputasi dilaporkan. Research this (uji coba TACT oleh Tanabe and Yuasa) mendapat perhatian international and menjadi pendahulu cell therapy for PAD.

Akhir-akhir this, not hanya uji coba small tetapi also meta-analisis which menganalisis bersama result from many uji clinical has diterbitkan. Wrong satunya mengintegrasikan analisis 23 uji coba terkontrol acak which menargetkan patient CLI (total 962 orang), and efektivitas and keamanan stem cell therapy dievaluasi (PubMed ID: 29977308).

Sebagai result analisis, kelompok which receive stem cell show peningkatan berikut dibandingkan with kelompok which hanya receive treatment konvensional:

  • Luka ulkus feet which sulit disembuhkan menjadi more mudah sembuh (tren perbaikan luka)
  • Indikator angiogenesis secara signifikan meningkat (pembentukan kapiler baru dipromosikan)
  • Peningkatan aliran darah and indikator oksigen seperti rasio tekanan darah pergelangan feet-lengan (ABI) and tekanan oksigen transkutan (TcO₂)
  • Pengurangan nyeri feet saat istirahat and perpanjangan jarak which can berjalan tanpa sense sakit (peningkatan ability berjalan)
  • Pengurangan risiko amputasi feet (amputasi tungkai bawah) in periode tertentu

With cara this, patient which receive stem cell therapy show peningkatan in indikator objektif aliran darah, gejala and ability motorik meningkat, and more lanjut proporsi which until pada amputasi large dikurangi has shown.

Sementara beberapa research show variasi in tingkat efektivitas, secara keseluruhan, possibility bahwa feet which not bisa diselamatkan with treatment konvensional can diselamatkan with stem cell therapy disarankan.

More lanjut, research clinical use stem cell sumber cell baru, stem cell which berasal from tali center (WJ-MSC) sedang muncul. Misalnya, in uji clinical fase I which dilaporkan pada tahun 2024, WJ-MSC which obtained from donor lain disuntikkan ke in otot feet pada patient CLI berat which disertai with diabetes, and keamanan and efektivitasnya diamati.

Sebagai hasilnya, semua patient which receive treatment menghindari amputasi feet (termasuk amputasi jari feet) selama enam bulan, and not there is efek samping which serius dilaporkan. Selain that, 6 bulan after treatment, peringan which signifikan in sense sakit feet (skor VAS) and perpanjangan waktu when can berjalan tanpa sense sakit, as well as peningkatan in skor fungsi feet (FADI) diamati.

Meskipun jumlah patient small, this is report which bermakna which show peningkatan large which obtained with therapy WJ-MSC latest which "sense sakit feet berkurang and can berjalan" (PubMed ID: 38112806). Selain that, berbagai uji clinical therapy PAD use berbagai stem cell sedang berlangsung di country-country di seluruh world, and bukti baru continuously terakumulasi.

Akumulasi research this bring stem cell therapy more dekat ke pilihan treatment which more mapan.

Keamanan Stem cell therapy for Disease Arteri Perifer and Efek Samping

When datang ke method treatment baru, keamanan and efek samping also can menjadi perhatian.

Singkatnya, stem cell therapy for disease arteri perifer has melaporkan keamanan which secara keseluruhan good in research saat this. In analisis which mengintegrasikan many uji clinical, not there is efek samping serius (kejadian bad) from stem cell therapy which diidentifikasi.

Khususnya, not there is report reaksi penolakan imun which parah or kematian related treatment, and dianggap bahwa not there is kekhawatiran keamanan which large. Sebaliknya, bagi patient CLI which not have cara for menangani treatment konvensional, manfaat which mungkin obtained mungkin more large daripada risikonya.

Faktanya, efek samping which dilaporkan sangat ringan. Misalnya, nyeri sementara or pembengkakan di tempat injeksi cell, demam ringan or kelelahan saat infus sometimes-sometimes diamati, tetapi semuanya bersifat sementara and menghilang with penanganan which tepat.

There is also kasus di mana perdarahan internal small (hematoma) terjadi from injeksi, tetapi this also membaik secara alami and not masalah. With kata lain, not there is komplikasi which more serius daripada that which dilaporkan.

Also, mengenai penggunaan stem cell from orang lain (cell which berasal from donor), reaksi penolakan which dikhawatirkan saat this not diamati. Hal this dipandu oleh fakta bahwa MSC that sendiri have fungsi mengatur kekebalan, menjadikan cell which masuk ke tubuh sulit for diserang = ditolak.

Sebagai catatan tambahan about keamanan, stem cell therapy is therapy rendah-invasif use injeksi or infus, and dibandingkan with operasi bedah large seperti membuat bypass large di pembuluh darah dada or feet, beban fisik pada patient berkurang secara signifikan.

Bahkan in uji clinical stem cell which berasal from tali center which disebutkan sebelumnya, not there is efek samping which dilaporkan selama periode tindak lanjut enam bulan. Selain keamanan stem cell therapy that sendiri, fakta bahwa process care that sendiri is method which ramah patient is keuntungan utama.

From di atas, stem cell therapy for disease arteri perifer can dikatakan sebagai therapy baru which relatif safe for diterima.
