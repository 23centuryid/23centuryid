Reason Cell Wharton's Jelly from Tali Pusat Memiliki Risk Penolakan Sangat Low

22 Maret 2025
  • Stem cell & Regenerative Therapy

Cell Wharton's Jelly is stem cell which diambil from "Wharton's Jelly" (gel Wharton) which found in in tali center (tali pusar) which obtained time persalinan. Wharton's Jelly is tissue ikat lunak which membungkus pembuluh blood in tali center, and bagian this mengandung stem cell mesenchymal (MSC) which rich.

Especially, stem cell which berasal from Wharton's Jelly (WJ-MSC) dikatakan less possibility experience penolakan time ditransplantasikan to orang lain, and dianggap very menjanjikan in stem cell therapy generasi berikutnya.

In artikel this, we explain reason scientific why WJ-MSC not mudah ditolak, with menyentuh latar belakang imunologi which kompleks, so that You can receive stem cell therapy in Malaysia with ketenangan pikiran.

What itu Penolakan? Hubungannya with HLA

In transplantasi medical, "penolakan" is reaksi in which system kekebalan tubuh mengenali organ or cell which ditransplantasikan sebagai "not milik sendiri" and berusaha menyerang and mengeluarkannya sebagai benda asing.

System kekebalan we biasanya bertugas melindungi tubuh from patogen seperti virus and bakteri, tetapi in therapy transplantasi, fungsi pertahanan this justru create problem.

For example, in transplantasi organ, when cell kekebalan mengenali information on permukaan organ which ditransplantasikan sebagai "benda asing", limfosit and cell lainnya mulai menyerang, menyebabkan kerusakan on organ which ditransplantasikan. Fenomena this disebut "penolakan".

Protein which disebut HLA (Human Leukocyte Antigen / Antigen Leukosit Human) very terlibat in identifikasi imun this. HLA there is in permukaan all cell and function seperti "ID tubuh" which unique for setiap individual. Cell kekebalan memeriksa HLA this for menentukan is that "diri sendiri" or "not diri sendiri".

Oleh because that, in transplantasi, if tipe HLA donor (pemberi) and penerima different, system kekebalan tubuh cenderung menganggap cell which ditransplantasikan sebagai benda asing, enhance possibility penolakan.

For mencegah penolakan this, institution medical biasanya perform tes kecocokan which liver-liver so that tipe HLA donor and penerima cocok sebanyak mungkin. Selain that, if risk penolakan tetap there is, drug imunosupresif can used sesuai kebutuhan for menekan fungsi kekebalan and memungkinkan transplantasi which safe.

Why Cell Wharton's Jelly Sulit Ditolak

WJ-MSC have beberapa karakteristik imunologis which make cell-cell this less possibility ditolak. Berikut is fitur main:

Ekspresi Antigen HLA Very Low

Wrong satu karakteristik WJ-MSC is jumlah ekspresi HLA (Human Leukocyte Antigen) on permukaan selnya very few. HLA is marker important which used cell kekebalan for membedakan "diri sendiri" and "not diri sendiri", and in therapy transplantasi, is molekul kunci in penolakan imun.

Secara spesifik, antigen MHC kelas I (HLA-ABC) diungkapkan on tingkat which very low, and antigen MHC kelas II (HLA-DR), which mudah bereaksi terhadap system kekebalan orang lain, hampir not diungkapkan same sekali.

Because ekspresi which low this, WJ-MSC not mudah dikenali oleh cell kekebalan, especially cell T, sebagai "benda asing".

Akibatnya, sifat imunogenik WJ-MSC, yaitu ability for memicu respons kekebalan, very ditekan, and tingkat penerimaan which high can diharapkan bahkan for transplantasi allogeneic (cell from orang lain).

Not Have "Sinyal Co-stimulasi" which Mengaktifkan Cell Kekebalan

Biasanya, for system kekebalan show respons which strong terhadap benda asing from luar, diperlukan dua sinyal. Sinyal pertama is pengenalan "antigen HLA", and sinyal kedua is stimulus tambahan which disebut "sinyal co-stimulasi".

Limfosit seperti cell T and cell B perlu kedua sinyal for sepenuhnya teraktivasi and mulai menyerang.

Sinyal co-stimulasi diteruskan oleh molekul seperti CD80 and CD86, tetapi research has show bahwa Wharton's Jelly stem cell (WJ-MSC) hampir not mengekspresikan molekul co-stimulasi this.

Oleh because that, bahkan if WJ-MSC found oleh cell kekebalan, "perintah for menyerang" from sinyal kedua not ditransmisikan, so that cell T not sepenuhnya teraktivasi and not mudah menyebabkan penolakan.

Fitur this is wrong satu faktor main which make WJ-MSC diterima with tenang in in tubuh.

Mensekresikan Sitokin Imunosupresif for Menekan Peradangan

Wharton's Jelly stem cell (WJ-MSC) not hanya cell which sulit diserang system kekebalan, tetapi also have "fungsi kontrol" which menyesuaikan fungsi system kekebalan in sekitarnya.

Sarana utamanya is sekresi sitokin, which merupakan zat komunikasi antar cell.

WJ-MSC known mensekresikan on tingkat high sitokin anti-inflammation seperti "Interleukin 10 (IL-10)" and "Transforming Growth Factor β (TGF-β)", which have efek menekan respons kekebalan which berlebihan.

Zat-zat this menghambat aktivitas cell kekebalan which berlebihan and calm respons inflammation, create lingkungan in which respons kekebalan less mungkin happen.

With cara this, WJ-MSC create lingkungan in sekitarnya in which respons kekebalan not mudah happen, and hasilnya, cell-cell more stabil in tubuh after transplantasi and mudah ditanam. This is wrong satu elemen important which mengarah to penghindaran penolakan.

Mengekspresikan HLA-G, Molekul which Terlibat in Toleransi Imun

Wharton's Jelly stem cell (WJ-MSC) known mengekspresikan molekul tipe HLA special which disebut "HLA-G". HLA-G is "faktor toleransi imun" which work for mencegah janin ditolak oleh system kekebalan ibu selama kehamilan, and also found in alam.

With mengekspresikan HLA-G, when WJ-MSC ditransplantasikan to in tubuh, cell-cell less possibility diserang oleh cell kekebalan. HLA-G known mendorong peningkatan "cell T pengatur (Treg)", which menekan fungsi kekebalan, and has found for reduce respons kekebalan which berlebihan.

With cara this, WJ-MSC not hanya have struktur which sulit dilihat sebagai "enemy" oleh kekebalan, tetapi also have ability for secara aktif meringankan ketegangan kekebalan and create lingkungan which diterima in in tubuh.

POIN: Seperti which dijelaskan in atas, Wharton's Jelly stem cells have tiga karakteristik seimbang: "not mencolok", "not merangsang", and "justru calm kekebalan". Kombinasi this menghasilkan risk penolakan which very low although cell berasal from orang lain, which merupakan wrong satu karakteristik unique they.

Makna Wharton's Jelly Tidak Mengandung Blood

Wrong satu reason why Wharton's Jelly stem cell (WJ-MSC) less possibility experience penolakan is fakta bahwa "tissue Wharton's Jelly not mengandung komponen blood".

This very related with keamanan imunologis time mengtransplantasikan WJ-MSC to orang lain.

Wharton's Jelly, which terletak in tali center, is tissue ikat which membungkus pembuluh blood. Because lokasinya, tissue this not mengandung cell blood red or cell blood white seperti komponen blood. Oleh because that, when stem cell which diambil from bagian this ditransplantasikan, possibility campuran antigen golongan blood donor or cell kekebalan donor (limfosit) very low.

This berarti bahwa risk bahwa "komponen blood donor masuk to in tubuh bersama-same" can dihindari, which secara teknis and imunologis merupakan advantage large.

Bahkan when stem cell which diambil from tissue lain seperti sumsum bone ditransplantasikan, has dikonfirmasi bahwa antigen golongan blood ABO hampir not diungkapkan. Oleh because that, transplantasi stem cell can successful bahkan without kecocokan golongan blood.

However, because WJ-MSC seperti "not including komponen which berasal from blood since tahap pengambilan", that is bahan tambahan which provide ketenangan pikiran.

Selain that, because produk cell from Wharton's Jelly less possibility bercampur with cell kekebalan donor seperti cell T and cell B, risk "disease graft-versus-host (GVHD)", in which cangkokan menyerang system kekebalan penerima, also very low.

With cara this, struktur "without blood" is faktor which melengkapi in menghindari penolakan imun for WJ-MSC, and have makna important.

Perbandingan Risk Penolakan: Wharton's Jelly, Sumsum Bone, and Stem cell Berasal Lemak

In stem cell therapy, reaksi penolakan imun terhadap cell which ditransplantasikan is problem important for dihindari. In here, we membandingkan "Wharton's Jelly stem cell", "bone marrow-derived stem cell", and "adipose-derived stem cell (with asumsi autotransplantation)" from tiga jenis stem cell.

Wharton's Jelly Stem cell (WJ-MSC)

  • WJ-MSC mengekspresikan antigen HLA very low, especially hampir not there is ekspresi HLA-DR which mudah bereaksi terhadap cell kekebalan.
  • More lanjut, not have molekul co-stimulasi T cell (CD80, CD86 dll), and have struktur which sulit diserang oleh cell kekebalan.
  • Mensekresikan sitokin imunosupresif tingkat high seperti IL-10 and TGF-β, create lingkungan in which peradangan ditekan and fungsi kekebalan tetap tenang.
  • Cell berasal from tali center bayi new lahir, very young, and not terpengaruh oleh kerusakan lingkungan or penuaan.
  • Tissue Wharton's Jelly which diambil not mengandung komponen blood, so that risk campuran antigen golongan blood ABO or cell kekebalan donor very low, and keamanan high.
  • From karakteristik this, diharapkan WJ-MSC have kompatibilitas transplantasi which very high bahkan for transplantasi allogeneic (from orang lain).

Bone Marrow-Derived Stem cell (BM-MSC)

  • MSC which berasal from sumsum bone mengekspresikan HLA kelas I (HLA-ABC) on tingkat sedang, and ekspresi HLA-DR (kelas II) mudah diinduksi in lingkungan inflammation tubuh, cenderung became target imun.
  • In situasi tertentu can mengekspresikan molekul co-stimulasi, which can mengaktifkan cell T and became pemicu respons penolakan.
  • Although happen sekresi IL-10 and TGF-β, efek penghambatan they on tingkat penekan dibandingkan WJ-MSC, and bervariasi tergantung usia individual.
  • Pengambilan sumsum bone melibatkan invasivitas, and on cell which berasal from donor which more old, kekhawatiran about peningkatan imunogenisitas and penurunan fungsi terdapat.
  • From latar belakang this, BM-MSC relatif safe in autotransplantation (transplantasi diri sendiri), tetapi in hal transplantasi allogeneic, mungkin diperlukan tindakan seperti imunosupresif.

Adipose-Derived Stem cell (AD-MSC, with asumsi autotransplantation)

  • In kasus autotransplantation use stem cell which diambil from tissue lemak they sendiri, system kekebalan not mengenalinya sebagai benda asing, jadi secara teoritis not there is risk penolakan.
  • Because tipe HLA true-true same, possibility system kekebalan menyerang very low, and tes kecocokan before not diperlukan.
  • However, not sepenuhnya can dikecualikan bahwa reaksi which tak terduga mungkin happen tergantung on lingkungan kekebalan local when ditransplantasikan to area radang.
  • Also, cell which obtained from tissue lemak donor dipengaruhi oleh usia and keadaan health donor, and quality cell and ability regeneration mudah bervariasi antar individual.
  • Although keamanan imun transplantasi in hal penolakan very high in hal transplantasi otomatis, there is challenge in fungsi cell and stabilitas efek.

In stem cell therapy, pertimbangan keamanan imun terhadap penolakan very important. Berikut is ringkasan perbandingan from ketiga jenis stem cell.

Ringkasan

Reason why stem cell which berasal from Wharton's Jelly (WJ-MSC) less possibility experience penolakan berasal from beberapa karakteristik imunologis. Pertama, jumlah ekspresi HLA (Human Leukocyte Antigen) very low, so that cell kekebalan sulit menemukannya and have sifat "not mencolok". Kedua, hampir not have molekul co-stimulasi which mengaktifkan cell T, mempertahankan keadaan "not merangsang" system kekebalan. Selain that, with mensekresikan sitokin imunosupresif seperti IL-10 and TGF-β, and with mengekspresikan HLA-G which terlibat in toleransi imun, WJ-MSC have ability for secara aktif "make enemy became friend". Kombinasi from elemen-elemen this memungkinkan WJ-MSC which berasal from orang lain for diterima with lancar in in tubuh and mudah ditanam after transplantasi. Karakteristik "toleransi imun" which WJ-MSC miliki secara intrinsik is cell which very special from sudut pandang imunologi, and is pilihan which very menjanjikan in stem cell therapy and therapy regenerative. Research have take place, and in future, diharapkan can used sebagai "sumber stem cell universal" which can used without khawatir about penolakan, and will applied more spacious in berbagai care medical.
