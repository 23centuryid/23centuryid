Alasan Sel Wharton's Jelly dari Tali Pusat Memiliki Risiko Penolakan Sangat Rendah

22 Maret 2025
  • Stem Cell & Regenerative Therapy

Cell Wharton's Jelly is stem cell which diambil from "Wharton's Jelly" (gel Wharton) which found di in tali center (tali pusar) which obtained saat persalinan. Wharton's Jelly is jaringan ikat lunak which membungkus pembuluh darah di tali center, and bagian this mengandung stem cell mesenchymal (MSC) which kaya.

Khususnya, stem cell which berasal from Wharton's Jelly (WJ-MSC) dikatakan kurang possibility mengalami penolakan saat ditransplantasikan ke orang lain, and dianggap sangat menjanjikan in stem cell therapy generasi berikutnya.

In artikel this, we menjelaskan alasan ilmiah why WJ-MSC not mudah ditolak, with menyentuh latar belakang imunologi which kompleks, so that You can receive stem cell therapy di Malaysia with ketenangan pikiran.

Apa itu Penolakan? Hubungannya dengan HLA

In transplantasi medical, "penolakan" is reaksi di mana system kekebalan tubuh mengenali organ or cell which ditransplantasikan sebagai "not milik sendiri" and berusaha menyerang and mengeluarkannya sebagai benda asing.

System kekebalan we biasanya bertugas melindungi tubuh from patogen seperti virus and bakteri, tetapi in therapy transplantasi, fungsi pertahanan this justru menciptakan masalah.

Misalnya, in transplantasi organ, when cell kekebalan mengenali information pada permukaan organ which ditransplantasikan sebagai "benda asing", limfosit and cell lainnya mulai menyerang, menyebabkan kerusakan pada organ which ditransplantasikan. Fenomena this disebut "penolakan".

Protein which disebut HLA (Human Leukocyte Antigen / Antigen Leukosit Human) sangat terlibat in identifikasi imun this. HLA there is di permukaan semua cell and berfungsi seperti "ID tubuh" which unik for setiap individu. Cell kekebalan memeriksa HLA this for menentukan apakah that "diri sendiri" or "not diri sendiri".

Oleh because that, in transplantasi, jika tipe HLA donor (pemberi) and penerima berbeda, system kekebalan tubuh cenderung menganggap cell which ditransplantasikan sebagai benda asing, enhance possibility penolakan.

For mencegah penolakan this, institusi medical biasanya perform tes kecocokan which hati-hati so that tipe HLA donor and penerima cocok sebanyak mungkin. Selain that, jika risiko penolakan tetap there is, drug imunosupresif can used sesuai kebutuhan for menekan fungsi kekebalan and memungkinkan transplantasi which safe.

Mengapa Sel Wharton's Jelly Sulit Ditolak

WJ-MSC have beberapa karakteristik imunologis which membuat cell-cell this kurang possibility ditolak. Berikut is fitur utama:

Ekspresi Antigen HLA Sangat Rendah

Wrong satu karakteristik WJ-MSC is jumlah ekspresi HLA (Human Leukocyte Antigen) pada permukaan selnya sangat few. HLA is penanda penting which used cell kekebalan for membedakan "diri sendiri" and "not diri sendiri", and in therapy transplantasi, is molekul kunci in penolakan imun.

Secara spesifik, antigen MHC kelas I (HLA-ABC) diungkapkan pada tingkat which sangat rendah, and antigen MHC kelas II (HLA-DR), which mudah bereaksi terhadap system kekebalan orang lain, hampir not diungkapkan sama sekali.

Because ekspresi which rendah this, WJ-MSC not mudah dikenali oleh cell kekebalan, terutama cell T, sebagai "benda asing".

Akibatnya, sifat imunogenik WJ-MSC, yaitu ability for memicu respons kekebalan, sangat ditekan, and tingkat penerimaan which tinggi can diharapkan bahkan for transplantasi allogeneic (cell from orang lain).

Not Have "Sinyal Co-stimulasi" which Mengaktifkan Cell Kekebalan

Biasanya, for system kekebalan show respons which kuat terhadap benda asing from luar, diperlukan dua sinyal. Sinyal pertama is pengenalan "antigen HLA", and sinyal kedua is stimulus tambahan which disebut "sinyal co-stimulasi".

Limfosit seperti cell T and cell B perlu kedua sinyal for sepenuhnya teraktivasi and mulai menyerang.

Sinyal co-stimulasi diteruskan oleh molekul seperti CD80 and CD86, tetapi research has show bahwa Wharton's Jelly stem cell (WJ-MSC) hampir not mengekspresikan molekul co-stimulasi this.

Oleh because that, bahkan jika WJ-MSC found oleh cell kekebalan, "perintah for menyerang" from sinyal kedua not ditransmisikan, so that cell T not sepenuhnya teraktivasi and not mudah menyebabkan penolakan.

Fitur this is wrong satu faktor utama which membuat WJ-MSC diterima with tenang di in tubuh.

Mensekresikan Sitokin Imunosupresif for Menekan Peradangan

Wharton's Jelly stem cell (WJ-MSC) not hanya cell which sulit diserang system kekebalan, tetapi also have "fungsi kontrol" which menyesuaikan fungsi system kekebalan di sekitarnya.

Sarana utamanya is sekresi sitokin, which merupakan zat komunikasi antar cell.

WJ-MSC known mensekresikan pada tingkat tinggi sitokin anti-inflammation seperti "Interleukin 10 (IL-10)" and "Transforming Growth Factor β (TGF-β)", which have efek menekan respons kekebalan which berlebihan.

Zat-zat this menghambat aktivitas cell kekebalan which berlebihan and menenangkan respons inflammation, menciptakan lingkungan di mana respons kekebalan kurang mungkin terjadi.

With cara this, WJ-MSC menciptakan lingkungan di sekitarnya di mana respons kekebalan not mudah terjadi, and hasilnya, cell-cell more stabil in tubuh after transplantasi and mudah ditanam. This is wrong satu elemen penting which mengarah ke penghindaran penolakan.

Mengekspresikan HLA-G, Molekul which Terlibat in Toleransi Imun

Wharton's Jelly stem cell (WJ-MSC) known mengekspresikan molekul tipe HLA special which disebut "HLA-G". HLA-G is "faktor toleransi imun" which bekerja for mencegah janin ditolak oleh system kekebalan ibu selama kehamilan, and also found di alam.

With mengekspresikan HLA-G, when WJ-MSC ditransplantasikan ke in tubuh, cell-cell kurang possibility diserang oleh cell kekebalan. HLA-G known mendorong peningkatan "cell T pengatur (Treg)", which menekan fungsi kekebalan, and has found for reduce respons kekebalan which berlebihan.

With cara this, WJ-MSC not hanya have struktur which sulit dilihat sebagai "musuh" oleh kekebalan, tetapi also have ability for secara aktif meringankan ketegangan kekebalan and menciptakan lingkungan which diterima di in tubuh.

POIN: Seperti which dijelaskan di atas, Wharton's Jelly stem cells have tiga karakteristik seimbang: "not mencolok", "not merangsang", and "justru menenangkan kekebalan". Kombinasi this menghasilkan risiko penolakan which sangat rendah meskipun cell berasal from orang lain, which merupakan wrong satu karakteristik unik they.

Makna Wharton's Jelly Tidak Mengandung Darah

Wrong satu alasan why Wharton's Jelly stem cell (WJ-MSC) kurang possibility mengalami penolakan is fakta bahwa "jaringan Wharton's Jelly not mengandung komponen darah".

This sangat related with keamanan imunologis saat mengtransplantasikan WJ-MSC ke orang lain.

Wharton's Jelly, which terletak di tali center, is jaringan ikat which membungkus pembuluh darah. Because lokasinya, jaringan this not mengandung cell darah merah or cell darah putih seperti komponen darah. Oleh because that, when stem cell which diambil from bagian this ditransplantasikan, possibility campuran antigen golongan darah donor or cell kekebalan donor (limfosit) sangat rendah.

This berarti bahwa risiko bahwa "komponen darah donor masuk ke in tubuh bersama-sama" can dihindari, which secara teknis and imunologis merupakan keuntungan large.

Bahkan when stem cell which diambil from jaringan lain seperti sumsum tulang ditransplantasikan, has dikonfirmasi bahwa antigen golongan darah ABO hampir not diungkapkan. Oleh because that, transplantasi stem cell can successful bahkan tanpa kecocokan golongan darah.

However, because WJ-MSC seperti "not termasuk komponen which berasal from darah since tahap pengambilan", that is bahan tambahan which provide ketenangan pikiran.

Selain that, because produk cell from Wharton's Jelly kurang possibility bercampur with cell kekebalan donor seperti cell T and cell B, risiko "disease graft-versus-host (GVHD)", di mana cangkokan menyerang system kekebalan penerima, also sangat rendah.

With cara this, struktur "tanpa darah" is faktor which melengkapi in menghindari penolakan imun for WJ-MSC, and have makna penting.

Perbandingan Risiko Penolakan: Wharton's Jelly, Sumsum Tulang, dan Sel Punca Berasal Lemak

In stem cell therapy, reaksi penolakan imun terhadap cell which ditransplantasikan is masalah penting for dihindari. Di sini, we membandingkan "Wharton's Jelly stem cell", "bone marrow-derived stem cell", and "adipose-derived stem cell (with asumsi autotransplantation)" from tiga jenis stem cell.

Wharton's Jelly Stem Cell (WJ-MSC)

  • WJ-MSC mengekspresikan antigen HLA sangat rendah, terutama hampir not there is ekspresi HLA-DR which mudah bereaksi terhadap cell kekebalan.
  • More lanjut, not have molekul co-stimulasi T cell (CD80, CD86 dll), and have struktur which sulit diserang oleh cell kekebalan.
  • Mensekresikan sitokin imunosupresif tingkat tinggi seperti IL-10 and TGF-β, menciptakan lingkungan di mana peradangan ditekan and fungsi kekebalan tetap tenang.
  • Cell berasal from tali center bayi baru lahir, sangat muda, and not terpengaruh oleh kerusakan lingkungan or penuaan.
  • Jaringan Wharton's Jelly which diambil not mengandung komponen darah, so that risiko campuran antigen golongan darah ABO or cell kekebalan donor sangat rendah, and keamanan tinggi.
  • From karakteristik this, diharapkan WJ-MSC have kompatibilitas transplantasi which sangat tinggi bahkan for transplantasi allogeneic (from orang lain).

Bone Marrow-Derived Stem Cell (BM-MSC)

  • MSC which berasal from sumsum tulang mengekspresikan HLA kelas I (HLA-ABC) pada tingkat sedang, and ekspresi HLA-DR (kelas II) mudah diinduksi di lingkungan inflammation tubuh, cenderung menjadi target imun.
  • In situasi tertentu can mengekspresikan molekul co-stimulasi, which can mengaktifkan cell T and menjadi pemicu respons penolakan.
  • Meskipun terjadi sekresi IL-10 and TGF-β, efek penghambatan they pada tingkat penekan dibandingkan WJ-MSC, and bervariasi tergantung usia individu.
  • Pengambilan sumsum tulang melibatkan invasivitas, and pada cell which berasal from donor which more tua, kekhawatiran about peningkatan imunogenisitas and penurunan fungsi terdapat.
  • From latar belakang this, BM-MSC relatif safe in autotransplantation (transplantasi diri sendiri), tetapi in hal transplantasi allogeneic, mungkin diperlukan tindakan seperti imunosupresif.

Adipose-Derived Stem Cell (AD-MSC, with asumsi autotransplantation)

  • In kasus autotransplantation use stem cell which diambil from jaringan lemak they sendiri, system kekebalan not mengenalinya sebagai benda asing, jadi secara teoritis not there is risiko penolakan.
  • Because tipe HLA true-true sama, possibility system kekebalan menyerang sangat rendah, and tes kecocokan sebelumnya not diperlukan.
  • However, not sepenuhnya can dikecualikan bahwa reaksi which tak terduga mungkin terjadi tergantung pada lingkungan kekebalan lokal when ditransplantasikan ke area radang.
  • Also, cell which obtained from jaringan lemak donor dipengaruhi oleh usia and keadaan health donor, and quality cell and ability regeneration mudah bervariasi antar individu.
  • Meskipun keamanan imun transplantasi in hal penolakan sangat tinggi in hal transplantasi otomatis, there is tantangan in fungsi cell and stabilitas efek.

In stem cell therapy, pertimbangan keamanan imun terhadap penolakan sangat penting. Berikut is ringkasan perbandingan from ketiga jenis stem cell.

Ringkasan

Alasan why stem cell which berasal from Wharton's Jelly (WJ-MSC) kurang possibility mengalami penolakan berasal from beberapa karakteristik imunologis. Pertama, jumlah ekspresi HLA (Human Leukocyte Antigen) sangat rendah, so that cell kekebalan sulit menemukannya and have sifat "not mencolok". Kedua, hampir not have molekul co-stimulasi which mengaktifkan cell T, mempertahankan keadaan "not merangsang" system kekebalan. Selain that, with mensekresikan sitokin imunosupresif seperti IL-10 and TGF-β, and with mengekspresikan HLA-G which terlibat in toleransi imun, WJ-MSC have ability for secara aktif "membuat musuh menjadi teman". Kombinasi from elemen-elemen this memungkinkan WJ-MSC which berasal from orang lain for diterima with lancar di in tubuh and mudah ditanam after transplantasi. Karakteristik "toleransi imun" which WJ-MSC miliki secara intrinsik is cell which sangat istimewa from sudut pandang imunologi, and is pilihan which sangat menjanjikan in stem cell therapy and therapy regenerative. Research sudah berlangsung, and di future, diharapkan can used sebagai "sumber stem cell universal" which can used tanpa khawatir about penolakan, and will applied more spacious in berbagai care medical.
